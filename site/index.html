CI status should not depend on a browser tab

  • Runs

    A failed run sits in a GitHub tab until someone looks. The fix starts late.

  • Runners

    A self-hosted runner goes offline and jobs queue. Nobody sees it until the queue is long.

  • Email

    GitHub emails you about failed runs you started. Those emails end up in a filter.

RunnerTray keeps this in one tray icon. The icon changes shape when a run fails, and a notification names the run. One click shows which runners are online, busy or offline.

Quiet on your PC

In a 60-minute test RunnerTray averaged 0.08 % CPU and about 90 MB of memory.

  • Refresh

    Every 15 seconds while runs are active, slower when nothing runs.

  • Requests

    One at a time. Unchanged data comes back as HTTP 304 and costs no rate limit.

  • Locked screen

    Paused until you use the PC again.

Panel built to WCAG 2.2 AA

Tab, the arrow keys, Enter, F5 and Esc reach every control. Text keeps 4.5:1 contrast and follows Windows text size and high contrast. Axe.Windows reports 0 errors.

Questions about RunnerTray

Short answers to what people ask before they install.

Ask in GitHub Discussions

Is RunnerTray free?

Yes. RunnerTray is free and open source under the MIT licence.

What can it see in my GitHub account?

Actions, metadata and self-hosted runners, all read-only. It cannot change code, settings or runs.

Will it use up my API rate limit?

No. It sends one request at a time, and unchanged data comes back as HTTP 304 at no cost.

Windows says “Windows protected your PC”. Is it safe?

It is not code-signed yet. Select More info, then Run anyway.

Does RunnerTray send telemetry?

No. It talks only to GitHub, and to Docker on your PC when you turn that on.

How do I uninstall RunnerTray?

Uninstall it from the tray menu or Settings > Apps. Its sign-in, startup entry and cache go too.
