Everything your CI is doing, without opening a browser

Live runs

Running and queued GitHub Actions runs across your repositories, with a live timer. Click a run to open it on GitHub.

Failure notifications

A Windows notification the moment a workflow fails. The tray icon turns red with a cross until the next run passes.

Self-hosted runners

See which organization runners are online, busy, or offline, with their labels. Runners in Docker on your PC show the repository and job they run.

Kind to your rate limit

One request at a time and conditional requests, as GitHub recommends. Refreshes fast while jobs run, slows down when quiet, pauses when you lock the screen.

Honest when things break

Offline, rate limited, or GitHub having a bad day: RunnerTray says so, shows the last good data with its time, and recovers by itself.

Updates itself

Installs per user without administrator rights and updates from GitHub Releases. A portable zip is available too.

Sign in with GitHub in under a minute

  1. Click Sign in with GitHub in the RunnerTray panel.
  2. Copy the code and paste it on github.com.
  3. Select Authorize. Done. No terminal, no token to create.

RunnerTray uses the RunnerTray GitHub App with read-only permissions. Your sign-in is kept in Windows Credential Manager and renewed automatically.

Questions

Is RunnerTray free?

Yes. It is free and open source under the MIT license.

What access does it need to my GitHub account?

Read-only: Actions, Metadata, and organization Self-hosted runners. It cannot change code, settings, or runs. You can revoke it at any time in GitHub settings.

Does it work with self-hosted runners?

Yes. It shows each organization runner as online, busy, or offline. For runners in Docker on your PC it also shows which repository and job each one runs.

Will it use up my API rate limit?

No. Requests that find nothing new are answered with "304 Not Modified", which does not count against the limit. RunnerTray also pauses while your screen is locked.

Windows says "Windows protected your PC". Is it safe?

RunnerTray is not code-signed yet. Select More info, then Run anyway. Every release is built from the public source code by GitHub Actions.

Does it send telemetry?

No. It talks only to GitHub, and to Docker on your PC if you turn that on.
